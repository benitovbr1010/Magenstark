# Verdauungstagebuch

Persönliche PWA zum Erfassen von Mahlzeiten, Stuhlgang, Befinden und Kontext. Details siehe `SPEC.md`.

## Stack

- Vite + React + TypeScript
- Tailwind CSS v4 (Design-Tokens in `src/index.css`)
- React Router (Tab-Navigation: Heute / Woche / Mein Weg)
- Supabase folgt in einem späteren Schritt (Auth, Postgres, Storage, Edge Functions)

## Entwicklung

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```
